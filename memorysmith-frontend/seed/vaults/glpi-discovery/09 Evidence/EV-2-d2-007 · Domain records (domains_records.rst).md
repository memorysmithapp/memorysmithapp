# EV-2-d2-007 · Domain records (domains_records.rst)

Evidência da documentação sobre o objeto **Domain record** (registro de domínio / registro DNS).

> [!quote] domains_records.rst · "Records"
> "A Record object stores all record types that can be found in a DNS zone or DNS configuration file: TXT, A, PTR, SDA, CNAME…" "This object must be associated to a Domain object." Pode-se adicionar um registro existente (campo *Link a record*) ou criar um novo.
> Passo-a-passo de criação: clicar em **+Add**; preencher os campos — **Name**, **Record type**, **Technician in charge**, **Group in charge**, **Creation date**, **TTL**, **Data**; clicar em **+Add**.
> Nota: "Record types are not limited to the default ones and can be customized using drop-down management."
