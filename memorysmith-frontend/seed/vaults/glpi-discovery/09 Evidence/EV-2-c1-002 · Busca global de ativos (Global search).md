# EV-2-c1-002 · Busca global de ativos (Global search)

> [!quote] modules/assets/global.rst
> "Menu `Asset > Global` allows to perform a global search on default view columns for allowed elements. (...) This search allows for instance to perform a query by status, IP or MAC address."

A busca é limitada a um conjunto de tipos: **Computer, Contact, Contract, Document, Monitor, NetworkEquipment, Peripheral, Phone, Printer, Software, SoftwareLicense, Ticket, Problem, Change, User, Group, Project, Supplier, Budget, Certificate, Line, Datacenter, DCRoom, Enclosure, PDU, Rack, Cluster, Domain**.

Busca sobre as colunas da *default view* de cada elemento permitido; exemplos de consulta: por status, endereço IP ou endereço MAC.
