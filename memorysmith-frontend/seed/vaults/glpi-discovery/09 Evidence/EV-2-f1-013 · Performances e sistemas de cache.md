> [!quote] modules/configuration/general/performances.rst — "Performances"
> "Displays information related to the different caching systems used by GLPI including:"
> - **PHP opcode cache**: melhora performance do engine PHP ao interpretar os arquivos PHP.
> - **User data cache**: cache de propósito geral usado pelo GLPI.
> - **Translation cache**: cache para traduções, evita reler os arquivos de locale.
> É possível **limpar os caches** a partir desta tela. Os caches de user data e translations podem ser trocados/configurados pelo comando CLI `cache:configure`.
