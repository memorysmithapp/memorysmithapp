# EV-2-d1-007 · Tipos de arquivo autorizados para upload de documentos

> [!quote] documents.rst · "Downloadable file types"
> Tabela com colunas NAME / EXTENSION / AUTHORIZED UPLOAD BY DEFAULT. Todos os tipos listados têm upload autorizado por padrão (Yes). Extensões incluem: imagens (ai, bmp, gif, jpg/jpeg, png, psd, svg, tif, xcf, mng), documentos de escritório (doc/docx, xls/xlsx, ppt/pptx, pdf, rtf, txt, odt/ods/odp/odb/odc/odg/odi/odf/odm/oth e templates ots/otg/otp/ott, sxw/sxc/sxi, sdd/sdw), áudio/vídeo (aiff, mp3, wav, mid, ogg, mov, avi, wmv, asf, swf, ra/ram/rm, mpg), arquivos compactados (bz2, gz, tgz, zip, sit, deb, rpm), código/dados (c, h, csv, json, xml, html, tex, dvi, pas, eps, ps), entre outros.

Esta lista corresponde ao dropdown **Setup > Dropdowns > Management > Document types** (ver EV-2-d1-006). Serve como referência dos formatos que podem ser anexados por padrão a documentos GLPI.
