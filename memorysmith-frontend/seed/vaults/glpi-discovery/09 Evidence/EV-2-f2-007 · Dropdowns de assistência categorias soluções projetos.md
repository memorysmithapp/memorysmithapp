# EV-2-f2-007 · Dropdowns de assistência categorias soluções projetos

> [!quote] assistance.rst — Ticket categories
> Lista **em árvore**, delegável por entidade. No formulário da categoria de chamado há (não limitado a): grupo responsável e técnico para atribuição automática de tickets; categoria padrão da base de conhecimento ao adicionar solução; visibilidade da categoria conforme interface (simplificada/padrão) ou objeto; **template de ticket** a usar (se escolhido, sobrepõe o definido na entidade ou por regra de negócio); categoria pai. Um link com as categorias da base de conhecimento é possível: clicar no help da categoria leva a todos os artigos daquela categoria.

> [!quote] assistance.rst — Task categories, Solution types, Request sources, Solution templates
> **Task categories**: em árvore, delegável por entidade (nome, categoria pai). **Solution types**: lista plana, delegável por entidade. **Request sources**: lista plana para todas as entidades; especifica se a fonte deve ser padrão para tickets e/ou collectors. **Solution templates**: lista plana, delegável por entidade; predefine conteúdo e tipo de uma solução, visível ou não da subentidade; **não pode ser traduzido**.

> [!quote] assistance.rst — Project states/types/task types
> **Project states**: lista plana para todas as entidades; define os status aplicados a um projeto e seu estado. **Project types**: lista plana para todas as entidades. **Project task types**: lista plana para todas as entidades. Abas comuns: tradução e all.
