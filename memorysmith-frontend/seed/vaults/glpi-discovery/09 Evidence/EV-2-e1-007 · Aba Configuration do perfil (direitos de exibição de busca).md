# EV-2-e1-007 · Aba Configuration do perfil (direitos de exibição de busca)

> [!quote] Setup permissions (configurationtab.rst)
> As 7 permissões padrão não são listadas. A permissão **Search result display** permite configurar as colunas exibidas no motor de busca do GLPI:
> - **User Display**: exibe uma aba *Personal view* que permite customização de exibição pelo usuário, objeto a objeto.
> - **Default Display**: permite modificar a exibição padrão que se aplica a cada usuário sem visão pessoal.

> [!note] Cobertura parcial
> O arquivo `configurationtab.rst` é um *orphan* enxuto e documenta apenas a permissão *Search result display*; as demais permissões da aba Configuration não estão detalhadas na documentação (ver INV-2-e1-002).
