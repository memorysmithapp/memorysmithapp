# EV-2-a2-003 · Status como visão específica

> [!quote] Status para ordenar/classificar hardware
> "Status information is frequently used to sort hardware that is disposed, available, assigned... It is possible to create new status values specific to the information system managed by GLPI." — `status.rst`.

> [!quote] Definição sob responsabilidade do administrador
> Definir novos status e os tipos de objeto a que se aplicam é responsabilidade do administrador GLPI, via configuração de dropdown (`dropdown configuration`). Esses status podem ser recursivos, para facilitar a gestão. — `status.rst`.

> [!quote] Como modificar e consultar status
> Modificar o status de um elemento pode ser feito pelo formulário do elemento ou por **mass actions**. Um relatório pode exibir resumo de status por tipo de ativo; a busca global no inventário permite consultar elementos por status. — `status.rst`.
