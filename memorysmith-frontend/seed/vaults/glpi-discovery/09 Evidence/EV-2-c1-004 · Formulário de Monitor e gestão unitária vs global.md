# EV-2-c1-004 · Formulário de Monitor e gestão unitária vs global

**Campos do formulário de Monitor:** Name; Location; Technician in charge; Group in charge; Alternate username number; Alternate username; User; Group; **Size**; UUID; Update source; Status; Monitor type; Manufacturer; Model; Serial number; Inventory number; Network; **Management type**; Comments; Ports.

> [!quote] Management type
> "It is possible to manage displays either unitary or globally. Unitary management corresponds to one display per computer while global management make the printer [sic] a virtual global element that will be connected to several computers. Global management allows to limit the number of elements to manage when these elements are not a strategic data in the assets management."

> [!note] Templates
> "It is possible to use templates with displays."

**Abas:** Impact Analysis; Operating systems; Software; Connections (Computer, outros ativos criados); Network Ports; Management; Contracts; Documents; Knowledge Base; Tickets; Problems; Changes; Links; Locks; Notes; Reservations; Domains; Appliances; Databases; Import information; Historical; All.

**Ações específicas:** conectar um display a um monitor (além das ações comuns).

> [!warning] Quirk do doc
> A explicação de *global management* menciona "printer" onde deveria ser "monitor/display" (aparente erro de redação no doc original, herdado de outra página).
