## Evidência

> [!quote] modules/tabs/external-links.rst — "External Links"
> A aba *External links* é usada para exibir links externos associados. Para alguns itens, os links externos são gerenciados pelo menu **Setup > External links**. Esses links podem usar campos do objeto como IP, nome etc. Remete a `configuration/external_links`.
>
> Exemplos: um link web `http://192.168.0.1` (IP obtido da porta de rede do hardware); um link RDP para acesso remoto `glpi://MSTSC.EXE,pc001` (nome "pc001" obtido do hardware).
