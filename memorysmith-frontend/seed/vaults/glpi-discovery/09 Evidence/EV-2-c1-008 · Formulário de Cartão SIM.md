# EV-2-c1-008 · Formulário de Cartão SIM

> [!quote] modules/assets/sim.rst
> "A SIM (Subscriber Identity Module) represents a SIM card used in mobile equipment such as telephones, tablets, 4G/5G modems, etc. You can manage these SIM cards as specific objects to track their use and allocation."

**Campos do formulário de SIM:** Code PIN; Code PIN2; Code PUK; Code PUK2; Line; **MSIN** (Mobile Subscriber Identification Number — últimos 8 ou 10 dígitos do IMSI); Serial number; Inventory number; Location; Status; User; Group; Comments.

**Abas:** Management (financeiro/administrativo); Documents; Locks; Contracts; Historical; All.

> [!note] O SIM tem um conjunto de campos reduzido e específico (códigos PIN/PUK, MSIN, Line) — não segue o modelo comum de hardware; não há Manufacturer/Model/Type nem abas de OS/Components/Network.
