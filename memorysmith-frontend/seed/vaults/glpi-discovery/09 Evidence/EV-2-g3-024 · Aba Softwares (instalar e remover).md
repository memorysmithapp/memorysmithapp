# EV-2-g3-024 · Aba Softwares (instalar e remover)

> [!quote] source/tabs/software.rst — "Software"
> "This field displays the list of applications installed on a machine (computer, network equipment, etc.)."
> **Install a Software**: em **software** selecionar a aplicação desejada, a **version**, e **install** (a partir da lista de aplicações existentes).
> **Delete a software**: marcar check box, **Actions**, **Delete permanently** (reversível refazendo a adição).
> "If you need to add or modify a software (not already present in the list), you need to go to the Assets > Software tab."
