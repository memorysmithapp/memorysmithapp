# EV-2-c2-004 · Enclosures

> [!quote] modules/assets/enclosures.rst · "Enclosures"
> "An enclosure is a type of equipment used to manage modular infrastructures, such as blade servers, storage bays or certain network equipment. It enables several physical elements to be grouped together in the same box, while retaining individual management of the components." Suportam templates.
