# EV-2-g3-017 · Aba Base de Conhecimento (vincular artigos)

> [!quote] source/tabs/knowledgebase.rst — "Knowledge base"
> "The Knowledge base tab is used to show or add linked knowledge base articles."
> "From this window, you can link an existing article to a GLPI object. However, it is not possible to create an article from this section." — para criar novo artigo, ir à base de conhecimento (Tools > Knowledge base).

> **Unlink an article**: via massive action — check box, **Actions**, **Delete permanently the relation with selected elements**, **Post**.
