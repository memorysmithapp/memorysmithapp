# EV-2-g3-007 · Feeds RSS

> [!quote] source/modules/tools/rssfeed.rst — "Manage RSS feeds"
> "GLPI allows to include RSS feeds in tool home page."
> Um feed RSS é por padrão **pessoal** (só visível pelo criador). Para torná-lo público, adicionam-se **targets**: entity, group, profile ou user.
> "A public RSS feed is visible by users associated with a profile if this profile has read permission for public RSS feeds."

> [!quote] Abas
> **Content**: consulta o número de itens exibidos (o conteúdo mostrado na home page).
> **Targets**: exibe e modifica a lista de alvos do feed.
> Inclui historical e all.
