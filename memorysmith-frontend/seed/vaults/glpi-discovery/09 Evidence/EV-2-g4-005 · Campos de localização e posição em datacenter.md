# EV-2-g4-005 · Localização e posição em datacenter

> [!quote] Location (`location.rst`)
> "You can add location manually or dynamically." Manual: selecionar do dropdown ou criar via **+** (ou **Setup > Dropdowns > Location**) informando Name, Code, As child of, Postal code, state, Building number, Longitude, Latitude, Altitude, Comments, Alias, Address, Town, Country, Room number. Dinâmica: via regras (`rulesmanagement`). Exclusão via ação massiva.

> [!quote] Data center position (`data_center_position.rst`)
> "The data position centre refers to the location (if this has been entered) within a rack positioned in a server room, itself housed in a datacenter." Posição do item dentro de um rack de um datacenter.
