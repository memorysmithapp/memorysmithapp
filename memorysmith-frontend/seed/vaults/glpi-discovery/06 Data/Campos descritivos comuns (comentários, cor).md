# Campos descritivos comuns (comentários, cor)

Dois campos comuns simples de natureza descritiva.

- **Comentários (comments):** campo de texto livre onde se registra qualquer informação.
- **Cor (color):** alguns objetos GLPI podem ter uma cor atribuída, escolhida por um seletor de cores ou informada por código Hex (ex.: `#000000`).
