# Referência (reference)

Campo comum inserido **manualmente**, que registra a **referência** impressa no próprio item (cartucho, consumível, etc.). Serve para gerenciar estoques, identificando o item físico. Relaciona-se aos campos de [[Limite de alerta (alert threshold)]] e [[Tipo de cartucho (cartridge type)]].
