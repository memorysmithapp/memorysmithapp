# Tipo de ativo (asset type)

Campo comum ([[Dropdown (lista suspensa customizável)]]) que classifica o item — usado de forma idêntica em muitos objetos (impressora, computador, periférico, etc.). Para computadores, por exemplo, permite indicar se a máquina é laptop, servidor, estação de trabalho, etc.

Não há tipos predefinidos: os valores devem ser criados (**+** → Nome → comentário opcional → **+ Add**). É reutilizável por [[Templates de itens (modelos)]] e regras; exclusão via [[Ações em massa (massive actions)]]. Parte de [[Modelo de Ativos (padrão comum)]].
