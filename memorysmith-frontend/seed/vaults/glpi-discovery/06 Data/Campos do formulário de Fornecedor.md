# Campos do formulário de Fornecedor

O [[Fornecedor na interface (Supplier) — visão do usuário|fornecedor]] é caracterizado por:

| Campo | Semântica |
|-------|-----------|
| **Name** | Nome do fornecedor. |
| **Third party type** | Tipo de terceiro (dropdown). |
| **Location** | Localização: endereço, código postal, cidade, país. |
| **Contato (site/telefone/fax)** | Dados de contato genéricos: web site, telefone, fax, etc. |

> [!note]
> O doc descreve a caracterização em prosa ("name, a third party type, a location (address, postal code, town, country) and a contact (web site, phone, fax...)"), sem listar formalmente cada campo do formulário. Contatos pessoais (pessoas) são objetos separados, ligados pela aba Contacts — ver [[Distinção Fornecedor × Contato (regra)]].
