# Campos de Licença de Software

Campos da aba **Licenses** de [[Software (ativo, versões e licenças)]]. As licenças gerenciam direitos de uso, disponibilidade e custo, ligando-se a [[Gestão de Software e Licenças (processo)]] e [[Gestão Financeira de TI]].

| Campo | Observação |
|---|---|
| Name | Nome |
| Serial number | Nº de série |
| Number | Quantidade licenciada |
| Affected Items | Itens/usuários afetados |
| Type | Tipo de licença |
| Purchase version | Versão comprada |
| Version in use | Versão em uso |
| Expiration | Expiração (permite alertas de expiração) |
| Status | Estado |

> [!note] As licenças podem ser ligadas a equipamentos ou a usuários, e ter custos associados para gestão orçamentária.
