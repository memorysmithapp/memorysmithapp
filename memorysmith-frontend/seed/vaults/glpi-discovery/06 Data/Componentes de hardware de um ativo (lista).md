# Componentes de hardware de um ativo (lista)

Aba **Components** (computador, periférico, telefone, impressora) lista os componentes internos do equipamento:

BIOS · Processor · Memory · Hard Drive · Network card · Drive · Battery · Graphics card · Sound card · Controller.

Cada componente tem suas próprias informações (nome, modelo, marca, capacidade de memória, número de cores/threads etc.).
