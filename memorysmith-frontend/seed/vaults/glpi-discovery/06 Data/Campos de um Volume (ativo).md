Atributos de um volume anexado a um `Computer`, geridos na [[Aba Volumes (ativos)|aba Volumes]]:

| Campo | Semântica |
|---|---|
| name | Nome do volume |
| physical partition | Partição física correspondente |
| mount point | Ponto de montagem |
| file system | Sistema de arquivos |
| total size | Tamanho total |
| available size | Tamanho disponível |
| ciphering algorithm and type | Algoritmo e tipo de cifragem (criptografia do volume) |
