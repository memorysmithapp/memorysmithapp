# Campos da aba Volumes

Aba **Volumes** (computador, telefone, impressora): resume volumes e partições presentes (disco rígido, DVD; discos virtuais como Google Cloud podem aparecer se montados como drive de rede). Campos:

Name · Automatic inventory (Yes/No) · partition · Mount point · File system · Global size · Free size · Free percentage · **Encryption** (se o disco for criptografado, exibe um cadeado).
