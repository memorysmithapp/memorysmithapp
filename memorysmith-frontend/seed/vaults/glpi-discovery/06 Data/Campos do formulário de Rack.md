# Campos do formulário de Rack

Campos ao adicionar um [[Rack (ativo DCIM)]] (+ Add).

| Campo | Observação |
|---|---|
| Name | Nome |
| Data center position | Posição no datacenter ([[DCIM (Datacenter → Rack)]]) |
| Location | Localização |
| Technician in charge / Group in charge | Responsáveis |
| Serial number / Inventory number | Nº de série / patrimônio |
| User / Group | Usuário / grupo |
| Comments | Comentários |
| Position in room | Posição na sala |
| Number of units | Número de U (unidades) |
| Height | Altura |
| Max. Power (in watts) | Potência máxima |
| Max. weight | Peso máximo |
| Status | Estado |
| Rack type | Tipo (dropdown) |
| Manufacturer / Model | Fabricante / modelo |
| Server room | Sala de servidores (data-centers) |
| Door orientation in room | North, East, South, West |
| Width / Depth | Largura / profundidade |
| Measured power (in watts) | Potência medida |
| Background color | Cor de fundo (visualização) |

Aba **Items**: posição de cada elemento no rack.
