# Campos específicos da abertura simplificada

Além dos campos comuns, o formulário simplificado de abertura ([[Interface Simplificada (Helpdesk-Self-Service)]]) tem campos próprios:

| Campo | Semântica |
|-------|-----------|
| **Inform me about the actions taken** | Aparece se followups por e-mail configurados. Se `Yes`, o requerente é informado por e-mail dos processamentos. |
| **Mail** | Endereço para o qual as notificações são enviadas; se houver vários, usa o e-mail padrão das preferências, podendo escolher outro ou digitar (se o perfil não tiver e-mail). |
| **Associated elements** | Associa um item do inventário ao ticket; a lista depende dos parâmetros do perfil do usuário. |
| **Watchers** | Adiciona um observador e define parâmetros de notificação. |
