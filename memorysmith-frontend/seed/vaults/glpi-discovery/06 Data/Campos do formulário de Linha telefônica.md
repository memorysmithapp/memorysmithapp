# Campos do formulário de Linha telefônica

Campos do formulário de uma [[Linha telefônica (phone line)]].

## Campos básicos
- **Name**
- **Status**, **Location**, **User**, **Group**, **Comments**
- **Line type**: tipo de linha; dropdown customizável (botão **+** para novo tipo).

## Campos específicos
| Campo | Semântica |
|-------|-----------|
| **Caller number** | Número de telefone atribuído à linha. |
| **Caller name** | Usuário atribuído à linha. |
| **Line operator** | Operadora da linha; dropdown customizável (botão **+** para nova operadora). |
