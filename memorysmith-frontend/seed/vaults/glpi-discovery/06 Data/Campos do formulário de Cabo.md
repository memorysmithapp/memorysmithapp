# Campos do formulário de Cabo

Campos ao adicionar um [[Cabo (ativo)]] (+ Add).

| Campo | Observação |
|---|---|
| Name | Nome |
| Status | Estado |
| Cable Type | Tipo de cabo (USB, Ethernet, HDMI...); dropdown em setup > dropdowns > cable management |
| Technician in charge | Técnico responsável |
| Inventory number | Nº de patrimônio |
| Comments | Comentários |
| Cable strand | Fio/veio do cabo (seção do doc sem detalhamento) |
| Color | Cor |

**Endpoint A / Endpoint B** (por endpoint): Type of asset, The asset, The socket model, The socket, e a posição (se informada no equipamento). Ver [[Ligação de dois dispositivos por cabo (endpoints)]].
