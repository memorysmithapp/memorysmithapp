# Tipo de cartucho (cartridge type)

Campo comum ([[Dropdown (lista suspensa customizável)]]) que define o **tipo de cartucho** (laser, jato de tinta, etc.). Criação via **+** → Name → comentário opcional → **+ Add**. Listagem via **i** ou **Setup > Dropdowns > Cartridge types**; exclusão via "delete permanently" ou [[Ações em massa (massive actions)]]. Relaciona-se a [[Referência (reference)]] e [[Limite de alerta (alert threshold)]] na gestão de estoque.
