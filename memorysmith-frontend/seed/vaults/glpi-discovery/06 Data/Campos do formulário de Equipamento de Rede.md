# Campos do formulário de Equipamento de Rede

Campos da aba **Network device** de [[Equipamento de Rede (ativo)]].

| Campo | Observação |
|---|---|
| Name | Nome do equipamento |
| Data center position | Posição no datacenter ([[DCIM (Datacenter → Rack)]]) |
| Location | Localização |
| Technician in charge / Group in charge | Responsáveis |
| Alternate username number / Alternate username | Usuário alternativo |
| User / Group | Usuário/grupo associado |
| Comments | Comentários |
| Status | Estado do item |
| Network equipment type | Tipo (dropdown) |
| Manufacturer / Model | Fabricante / modelo |
| Serial number / Inventory number | Nº de série / patrimônio |
| Network | Rede |
| UUID | Identificador único |
| Update source | Fonte de atualização |

**Campos do inventário automático (GLPI Agent):** Agents, Public contact address, Agents Status, Useragent, Last contact, Request inventory, Inventory tag, Last inventory update. Ver [[Inventário automático (processo)]].

Outros campos aparecem nas abas OS, Volumes, Network Ports e Network Name (ver [[Campos da aba Portas de Rede (Network Ports)]]).
