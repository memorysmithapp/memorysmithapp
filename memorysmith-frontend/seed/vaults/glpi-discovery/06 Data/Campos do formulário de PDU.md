# Campos do formulário de PDU

Campos do formulário de [[PDU (Power Distribution Unit)]].

| Campo | Observação |
|---|---|
| Name | Nome |
| Data center position | Posição no datacenter ([[DCIM (Datacenter → Rack)]]) |
| Location | Localização |
| Technician in charge | Técnico responsável |
| Model | Modelo |
| Inventory number | Nº de patrimônio |
| Comments | Comentários |
| Status | Estado |
| Device type | Tipo do dispositivo (dropdown) |
| Manufacturer | Fabricante |
| Serial number | Nº de série |
| User | Usuário |

Aba **Plugs**: número de tomadas (sockets) disponíveis na PDU. Aba **Network Ports**: ver [[Campos da aba Portas de Rede (Network Ports)]].
