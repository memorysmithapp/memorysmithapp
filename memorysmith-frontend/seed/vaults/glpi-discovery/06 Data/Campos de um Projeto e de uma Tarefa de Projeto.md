# Campos de um Projeto e de uma Tarefa de Projeto

## Project
| Campo | Descrição |
|---|---|
| Name | Nome do projeto |
| Code | Código do projeto |
| State | Estado |
| Type | Tipo |
| Datas provisórias e reais | Início/fim planejados e reais |
| Percent done | Percentual concluído |
| As child of | Define o projeto como subprojeto (hierarquia) |
| Show on global GANTT | Inclui o projeto no GANTT global |
| Equipe | Usuários, grupos, fornecedores e contatos |

## Project task
| Campo | Descrição |
|---|---|
| Name | Nome da tarefa |
| State | Estado |
| Type | Tipo |
| Datas provisórias e reais | Início/fim planejados e reais |
| Percent done | Percentual concluído |
| Parent task | Tarefa pai (sub-tarefa) |
| Duração planejada / real | Reportada ao nível do projeto junto à duração dos tickets anexados |
| Equipe | Usuários, grupos, fornecedores e contatos |
