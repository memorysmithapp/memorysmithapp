# Campos de um Lembrete

Atributos de um [[Lembretes pessoais e públicos (Reminder)|lembrete]]:

| Campo | Descrição |
|---|---|
| Texto / anexos | Texto simples com arquivos anexos (aba Documents) |
| Lifetime | Tempo de vida do lembrete |
| Status | Estado do lembrete |
| Aparecer no planning | Se o lembrete aparece no planning dos alvos |
| Data de início | Se vazia, visível imediatamente |
| Data de fim | Se vazia, visível permanentemente; lembrete planejado não é apagado após ela |
| Targets | Entity, profile, group ou users (define visibilidade pública) |
