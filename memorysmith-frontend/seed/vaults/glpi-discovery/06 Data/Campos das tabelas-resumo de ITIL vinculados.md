Colunas da tabela-resumo exibida nas abas [[Aba Tickets vinculados]], [[Aba Problemas (Problems) vinculados]] e [[Aba Mudanças (Changes) vinculadas]] — o conjunto de campos é idêntico para os três objetos ITIL.

| Coluna | Semântica |
|---|---|
| Status | Situação atual do objeto ITIL |
| Data | Abertura ou vencimento, resolução ou fechamento — conforme o status |
| Prioridade | Prioridade do objeto |
| Solicitante(s) e técnico(s) atribuído(s) | Atores requester e assigned |
| Elementos associados | Itens vinculados ao objeto |
| Categoria | Categoria ITIL |
| Nome | Título do objeto |
| Nº de tarefas agendadas | Contagem de scheduled tasks |

> [!note] Em cada uma dessas abas, uma **segunda tabela** lista os objetos ITIL anexados aos elementos relacionados (não diretamente ao objeto atual).

Relaciona-se com [[Campos do formulário de Ticket]] e [[Ciclo de vida do ticket (visão do usuário)]].
