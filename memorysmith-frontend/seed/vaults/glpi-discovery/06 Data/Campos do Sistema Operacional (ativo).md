Elementos associados a um sistema operacional na [[Aba Sistema Operacional (ativos)|aba Operating system]] de um `Computer`:

| Campo | Semântica |
|---|---|
| Name | Nome do SO (catálogo em Setup > Drop-downs) |
| Version | Versão do SO |
| Architecture | Arquitetura (ex.: x86, x64) |
| Service Pack | Service pack aplicado |
| Kernel | Versão do kernel |
| Edition | Edição do SO |
| Product ID | Identificador de produto |
| Serial number | Número de série da licença/SO |

Os "títulos" (Name, e demais listas) são geridos como [[Dropdown (lista suspensa customizável)|dropdowns]] em **Setup > Drop-downs > Operating systems**.
