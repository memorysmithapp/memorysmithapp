# Tipo de gestão (unitária vs global)

Campo comum que define como um periférico é gerido:

- **Unitária:** um periférico por computador.
- **Global:** o periférico torna-se um elemento virtual global, conectável a vários computadores.

A gestão global reduz o número de elementos a gerir quando estes não são dado estratégico na gestão de ativos. Os valores são **fixos** — não é nativamente possível adicionar um tipo de gestão.
