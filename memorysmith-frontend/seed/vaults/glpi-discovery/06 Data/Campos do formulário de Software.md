# Campos do formulário de Software

Campos do formulário de [[Software (ativo, versões e licenças)]].

| Campo | Observação |
|---|---|
| Name | Nome (recomenda-se sem nº de versão) |
| Location | Localização |
| Technician in charge / Group in charge | Responsáveis |
| User / Group | Usuário / grupo |
| Comments | Comentários |
| Pictures | Imagens |

**Campos específicos do software:**

| Campo | Semântica |
|---|---|
| Upgrade From | Informativo (sem processamento): indica se é update de outro software |
| Software category | Agrupa o software na lista de software de um ativo |
| Associable to a ticket | Define se aparece no drop-down "Hardware" de um ticket |

Um software é, por padrão, associado a uma **entidade** ([[Modelo de Entidades (multi-tenancy)]]).
