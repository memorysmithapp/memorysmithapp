Aba **Default values** que define as preferências de exibição usadas **por padrão** para novos usuários. Podem ser sobrescritas por usuário — ver [[Campos das Preferências do Usuário]] e [[Personalização da Experiência do Usuário (capacidade)]].

## Personalization
Default language; Results to display by page (limitado ao valor do setup geral); Display the complete name in tree dropdowns; Show GLPI ID; Notifications for my changes (não vale para criação de ticket, sempre enviada como prova); PDF export font; Go to created item after creation; Date format; Number format; Display order of surnames/firstnames; Display counters; CSV delimiter; Results to display on home page (0 = só títulos das tabelas); **Keep devices when purging an item** (preservar componentes ao excluir o item).

## Assistance
Private followups by default; Private tasks by default; Tasks state by default; **Pre-select me as a technician when creating a ticket**; **Priority colors** (cores por nível de prioridade); Show new tickets on the home page; **Request sources by default**; Automatically refresh data (tickets list, project kanban) in minutes (0 = desativado).

## Due date progression
Cores da barra de progresso de um objeto conforme thresholds em percent, horas ou dias.

## Dashboards
Dashboards padrão da home (central), módulo de assistência, módulo de ativos e acima da lista de resultados de tickets.

> Relaciona-se ao [[Quadro Kanban]], à [[Matriz de prioridade (configuração urgência × impacto)]] e às [[Notificações (e-mail e canais)]].
