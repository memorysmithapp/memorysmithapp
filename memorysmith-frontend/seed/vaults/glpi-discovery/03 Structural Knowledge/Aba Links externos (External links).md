A aba **External links** exibe links externos associados ao item. Para alguns itens, esses links são gerenciados pelo menu **Setup > External links** e podem usar **campos do próprio objeto** (IP, nome etc.) para compor a URL dinamicamente.

Exemplos: link web `http://192.168.0.1` (IP obtido da porta de rede do hardware); link RDP `glpi://MSTSC.EXE,pc001` para acesso remoto (nome obtido do hardware).

Relaciona-se com [[Rede (portas, IP, VLAN)]] (origem dos campos usados). Faz parte das [[Abas genéricas dos formulários GLPI]].
