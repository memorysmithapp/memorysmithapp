# Abas do formulário de Contrato

O formulário de um [[Contrato na interface (Contract) — visão do usuário|contrato]] organiza-se em abas:

| Aba | Função |
|-----|--------|
| **Costs** | Define custos ligados ao contrato e imputados a um [[Orçamento na interface (Budget) — visão do usuário|orçamento]] GLPI. Cada custo tem nome, datas de início/fim e valor real; a aba soma todos os custos. Ver [[Adicionar um custo a um contrato (procedimento)]]. |
| **Suppliers** | Associa um ou vários [[Fornecedor na interface (Supplier) — visão do usuário|fornecedores]] ao contrato (via dropdown). |
| **Items** | Itens (ativos) cobertos pelo contrato; limitados por *Max number of items*. |
| **Documents** | Documentos anexados. |
| **External links** | Links externos. |
| **Notes** | Notas de texto livre. |
| **Historical** | Histórico de alterações. |
| **Debug** | Aba de depuração. |
| **All** | Visão consolidada de todas as abas. |

> [!note] Ponte doc×código
> Custos e orçamento remetem a [[Orçamentos e Custos]]; itens cobertos remetem à relação contrato↔ativo de [[Contratos (Contract)]].
