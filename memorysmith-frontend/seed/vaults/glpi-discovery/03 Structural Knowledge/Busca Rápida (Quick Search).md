# Busca Rápida (Quick Search)

A **busca rápida** é a ferramenta situada no canto superior direito da tela (a *search box* de [[Áreas da Interface do GLPI]]). Permite uma busca global — sobre objetos de tipos diferentes — a qualquer momento.

Busca entre elementos incluindo (não limitado a): Tickets, Problems, Changes, Projects, Computers, Monitors, Software, Network Equipment, Peripherals, Printers, Phones, Contacts, Suppliers, Documents, Budgets, Licenses, Users, Groups.

> [!note]
> A busca é feita **apenas nos campos exibidos por padrão** de cada tipo de elemento — equivale a uma busca `items seen` em cada tipo.

Distingue-se do formulário completo de busca por critérios descrito em [[Busca na Interface (uso do motor de busca)]]; ambos apoiam-se no [[Motor de Busca (Search Engine)]] (código).
