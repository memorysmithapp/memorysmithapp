> [!abstract]
> Continuous Integration é a prática de integrar e validar automaticamente mudanças de código em um repositório comum, várias vezes ao dia.

## Conceito

CI existe para atacar um problema específico: o custo de integração cresce de forma não linear com o tempo entre integrações. Integrar diariamente é trivial; integrar após três semanas é um projeto.

O elemento que faz CI funcionar não é a ferramenta, é a disciplina de manter a build verde: uma build quebrada tolerada por horas anula todo o mecanismo.

## Características

- Integração frequente em ramo comum
- Validação automatizada a cada mudança
- Build quebrada é prioridade máxima do time
- Pré-requisito para [[Continuous Delivery (CD)]]
