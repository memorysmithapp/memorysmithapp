> [!abstract]
> Output é o entregável tangível ou intangível produzido por uma atividade. É o que foi feito, não o que foi alcançado.

## Conceito

Output é a métrica de conveniência: fácil de contar, fácil de reportar, fácil de otimizar sem gerar valor nenhum. "127 chamados fechados" é output. Se os 127 voltarem na semana seguinte, o [[Outcome]] foi zero.

A distinção não é acadêmica — é o teste mais rápido para saber se um painel de indicadores mede valor ou mede atividade.

## Comparação

| | [[Output]] | [[Outcome]] |
|---|---|---|
| Natureza | Entregável | Resultado |
| Dono | Provedor | Consumidor |
| Pergunta | O que produzimos? | O que mudou para quem consome? |
| Exemplo | Relatório gerado | Decisão tomada com base nele |
| Risco | Otimizar o número sem gerar efeito | Difícil de medir diretamente |
