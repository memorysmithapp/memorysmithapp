O MVP é a peça-chave deste ciclo, servindo como o artefato construído para gerar dados que possibilitam a medição e o aprendizado.

## Estrutura da Hipótese

O livro sugere o seguinte modelo para declarar o que se busca aprender:

- **Nós acreditamos que este MVP vai conseguir** (resultado esperado).
- **Saberemos que isso aconteceu com base em** (métricas para validar as hipóteses).
