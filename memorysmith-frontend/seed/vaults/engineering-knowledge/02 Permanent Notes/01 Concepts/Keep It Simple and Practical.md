> [!abstract]
> Use o mínimo de passos necessários para alcançar o objetivo. Elimine o que não contribui para um resultado de valor.

## Conceito

Complexidade raramente é projetada — ela se acumula. Cada exceção tratada com um campo novo, cada incidente respondido com uma aprovação adicional. O princípio pede o movimento contrário e explícito: remover.

O critério útil é começar pelo caminho simples e adicionar complexidade só quando houver evidência de necessidade. O inverso — desenhar para todos os casos possíveis e simplificar depois — quase nunca acontece.

## Dinâmica

1. Desenhar para o caso comum, não para a exceção
2. Adicionar controle apenas com evidência de risco
3. Revisar periodicamente o que pode ser removido
4. Medir esforço para executar, não só resultado
