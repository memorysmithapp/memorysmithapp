## Módulo 4: Colocando tudo junto

Cobre as lições *Claude in action: use-cases by role* e *Other ways to work with Claude*.

## Resumo executivo

O módulo aterrissa o curso em duas direções. Primeiro por **papel**: casos de uso concretos para vendas, marketing, finanças, RH, jurídico e pesquisa. Depois por **superfície**: onde mais o Claude vive além do claude.ai — e a tese de que a inteligência é uma só, distribuída em interfaces que encontram o trabalho onde ele já acontece.

## Principais ideias

### O caso de uso é sempre o mesmo trabalho, com contexto diferente

Os exemplos por papel são variações de três verbos: **sintetizar** material disperso, **produzir** um entregável recorrente e **decodificar** um artefato herdado.

| Papel | Casos citados |
|---|---|
| Geral | Relatório de status de projeto · análise de padrões em feedback · empacotar guidelines de marca numa [[Agent Skill\|Skill]] |
| Vendas | Biblioteca de battle cards · preparação de negociação · relatórios de pipeline |
| Marketing | Análise de performance de campanha · adaptação de conteúdo entre canais |
| Finanças | Modelagem financeira · memorandos de investimento · entender e estender planilha herdada |
| RH | Guias de onboarding por função |
| Jurídico | Rastrear timelines de *discovery* e identificar padrões em documentos |
| Pesquisa | Planejar revisão de literatura · verificar estatísticas a partir de dados brutos |

### As superfícies do Claude

| Superfície | Melhor para | Onde roda |
|---|---|---|
| **Claude.ai** | Tarefas gerais, pesquisa, escrita, análise, criação de arquivos | Web, desktop, mobile |
| **[[Claude Code]]** | Desenvolvimento, navegação de codebase, fluxos git | Terminal, IDE ou navegador |
| **[[Claude Cowork]]** | Tarefas multi-etapa: briefs, documentos, organização de arquivos, análise | Desktop (web e mobile em beta) |
| **@Claude** | Colaboração em time, preparação de reunião, respostas em contexto | Slack |
| **Claude Design** | Protótipos de UI a partir de brief, sketch ou screenshot | Web |
| **Claude for Microsoft 365** | Editar no lugar e carregar contexto entre documentos | Sidebars de Excel, PowerPoint, Word e Outlook |
| **Claude in Chrome** | Pesquisa web, e-mail, automação de navegador | Sidebar do Chrome |

### A superfície escolhe onde o contexto já está

O argumento de fundo: cada superfície existe porque o **contexto** de um tipo de trabalho mora num lugar específico. O contexto da discussão do time está no Slack; o das dependências de fórmula está na planilha; o do sistema legado está no repositório; o do painel interno sem API está no navegador. Levar o Claude até lá custa menos que trazer o contexto para o chat.

> [!warning] Claude in Chrome está em beta público
> A recomendação da Anthropic é usá-lo em tarefas de baixo risco em sites confiáveis. A extensão pede permissão antes de ações de alto risco (compra, compartilhamento de dado pessoal) e bloqueia por padrão certas categorias de site.
