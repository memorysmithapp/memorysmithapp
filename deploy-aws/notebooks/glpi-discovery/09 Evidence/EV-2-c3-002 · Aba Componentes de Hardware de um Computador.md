> [!quote] modules/assets/tabs/components.rst — "Components"
> A aba `Components`, visível numa entrada `Computer`, permite gerenciar os componentes de hardware de um computador.
>
> - A adição/gestão do catálogo de componentes fica no menu **Setup > Components** (`modules/configuration/components`).
> - Se vários componentes do mesmo tipo são usados, eles são agrupados na visão.
> - Para adicionar um componente: primeiro seleciona-se a **família** na lista suspensa no topo da tabela, depois o **nome** e o **número** de componentes a adicionar.
> - A partir da visão de um computador, é possível modificar um componente clicando no link sob seu nome.
> - Para agir sobre vários componentes (modificar um elemento, ativar/alterar informações contábeis, excluir...), selecionam-se os componentes e usa-se o botão `Actions` no topo ou rodapé da lista. Se tipos diferentes de componentes, com características distintas, são selecionados para modificação, será perguntado a qual componente a modificação deve se aplicar.
> - O botão de seleção na coluna esquerda seleciona todos os componentes de uma vez; a seleção à direita da coluna de tipo (linha acinzentada) seleciona todos os componentes do mesmo tipo (processador, memória, interface de rede...).
> - É possível modificar as características de um componente apenas para um computador: na aba *Elements* do componente, clicar no link **Update**. Vários abas são então exibidas: "Element - Link name of component" (características), Management (info administrativa/contábil), Documents, History, Contract, Debug (só em modo Debug) e All.
> - Toda exclusão ou adição de um componente é registrada no histórico do computador.
> - Com inventário nativo/terceiro, as informações dos componentes podem ser importadas e atualizadas automaticamente.
