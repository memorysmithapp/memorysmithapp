> [!quote] modules/configuration/general/default_values.rst — "Default values"
> "This tabs allows to configure the display preferences that are used by default. They can be overridden for each user."
> **Personalization**: Default language; Results to display by page (limitado ao valor do setup geral); Display the complete name in tree dropdowns; Show GLPI ID; Notifications for my changes (não vale p/ criação de ticket, sempre enviada); PDF export font; Go to created item after creation; Date format; Number format; Display order of surnames/firstnames; Display counters; CSV delimiter; Results to display on home page (0 = só títulos das tabelas); Keep devices when purging an item.
> **Assistance**: Private followups by default; Private tasks by default; Tasks state by default; Pre-select me as a technician when creating a ticket; Priority colors; Show new tickets on the home page; Request sources by default; Automatically refresh data (tickets list, project kanban) in minutes (0 = desativado).
> **Due date progression**: define cores da barra de progresso conforme thresholds em percent, horas ou dias.
> **Dashboards**: configura dashboards padrão da home (central), módulo de assistência, módulo de ativos e acima da lista de resultados de tickets.
