# EV-2-g3-016 · Aba Itens (vincular ativos a um objeto)

> [!quote] source/tabs/item.rst — "Items"
> **Link a device**: pode-se anexar qualquer item da lista: Computer, Database, Device, Enclosure, Monitor, Network device, Phone, Printer, Rack, Server room, Software.
> "You can integrate your own devices or, if your profile allows, any other device."
> Para vincular um dos próprios: selecionar em **My devices** (busca por barra de pesquisa). Para vincular outro: selecionar o **tipo** do item e depois o equipamento. Vários elementos e tipos podem ser vinculados.
> **Unlink an item**: via **massive actions** — marcar check box, **Actions**, **Delete permanently the relation with selected elements**, **Post**.
