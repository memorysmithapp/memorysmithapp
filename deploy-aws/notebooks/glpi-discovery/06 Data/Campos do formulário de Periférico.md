# Campos do formulário de Periférico

Periférico = equipamento acessório conectado a um sistema principal (computador, servidor). Campos: Name, [[Campos comuns de um ativo (formulário)|Location, Technician/Group in charge, Alternate username(+number), User, Group, Comments, Status]], **Device type**, Manufacturer, Model, Serial number, Inventory number, **Management type**, Network, UUID, Update source.

- **Device type** — o doc referencia o campo comum `computer_type` para o tipo de dispositivo.
- Suporta [[Templates de itens (modelos)|templates]].
- Possui aba **Projects** além das [[Abas comuns de um ativo (visão do usuário)|comuns]]; sem ações específicas (usa as ações comuns).
