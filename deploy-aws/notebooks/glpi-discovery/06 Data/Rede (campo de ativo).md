# Rede (campo de ativo)

Campo comum ([[Dropdown (lista suspensa customizável)]]) que rotula a **rede** à qual o ativo pertence. É informação adicionada manualmente e pode ser pré-preenchida por um [[Templates de itens (modelos)|template]]. Criação via **+** → Nome → Comentário (opcional) → **+ Add**.

> [!warning] Desambiguação
> Este é um campo-rótulo simples do formulário do ativo. Não deve ser confundido com a modelagem de **portas de rede, endereços IP e VLANs** do ativo, coberta em [[Rede (portas, IP, VLAN)]].
