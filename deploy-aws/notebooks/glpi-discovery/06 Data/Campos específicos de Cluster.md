# Campos específicos de Cluster

Campos específicos do formulário de um [[Cluster (agrupamento de ativos)]] (além do nome e campos comuns):

| Campo | Semântica |
|-------|-----------|
| **UUID** | Identificador único do cluster. |
| **Version** | No caso de um cluster de software, número da versão. |
| **Update Source** | Como os dados do cluster foram atualizados (fonte de atualização). |

Os elementos do cluster (ativos) são geridos pela aba **Elements** e as interfaces de rede pela aba **Network ports** — ver [[Cluster (agrupamento de ativos)]].
