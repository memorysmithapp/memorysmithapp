# Campos do formulário de Enclosure

Campos ao adicionar um [[Enclosure (chassis modular)]] (+ Add).

| Campo | Observação |
|---|---|
| Name | Nome |
| Location | Localização |
| Technician in charge | Técnico responsável |
| Manufacturer | Fabricante |
| Serial number | Nº de série |
| User | Usuário |
| Power Supplies | Número de fontes de alimentação |
| Status | Estado |
| Model | Modelo |
| Inventory number | Nº de patrimônio |
| Comments | Comentários |

Aba **Components** permite adicionar Generic device, PCI device e Power supply (equipamento passivo sem software/firmware). Aba **Network Ports**: ver [[Campos da aba Portas de Rede (Network Ports)]].
