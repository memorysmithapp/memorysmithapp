# Campos de Versão de Software

Campos de uma **Versão** de [[Software (ativo, versões e licenças)]] — a versão é o elemento efetivamente instalável em um ativo.

| Campo | Observação |
|---|---|
| Name | Número da versão |
| Status | Segue a **DSL** (biblioteca de versões autorizadas — recomendação ITIL) |
| Operating system | SO em que a versão roda |
| Summary | Visão geral de instalações e entidades onde está instalado |
| Installations | Número de instalações da versão |
| Historical | Histórico de eventos |
| All | Todos os elementos anteriores |

Ver processo em [[Instalação e desinstalação de software (procedimento)]].
