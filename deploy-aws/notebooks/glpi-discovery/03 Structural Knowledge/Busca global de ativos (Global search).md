# Busca global de ativos (Global search)

O menu **Asset > Global** realiza uma busca global sobre as colunas da *default view* de um conjunto de tipos permitidos. Permite, por exemplo, consultar por **status**, **endereço IP** ou **endereço MAC** de uma só vez.

## Tipos abrangidos
Computer, Contact, Contract, Document, Monitor, NetworkEquipment, Peripheral, Phone, Printer, Software, SoftwareLicense, Ticket, Problem, Change, User, Group, Project, Supplier, Budget, Certificate, Line, Datacenter, DCRoom, Enclosure, PDU, Rack, Cluster, Domain.
