# Dicionário de dados (dictionary)

**Dicionário** (Dictionary) é, conforme o glossário oficial, um conjunto de regras que permite **modificar dados do GLPI**. É um caso de aplicação do [[Motor de Regras (engine)]] voltado à padronização/qualidade de dados (ex.: normalizar nomes de fabricantes, modelos, softwares durante o inventário).

Conceitos de regra relacionados no glossário:

- **Rule**: lista de critérios que disparam uma lista de ações se satisfeitos (ver [[Tipos de Regra]]).
- **Adaptive rule** (regra adaptativa): regra em que ao menos uma ação resulta de uma expressão regular definida em um critério.
- **Criteria**: elemento ou padrão usado por motores de busca, motores de regras e dicionários para selecionar informação ou executar ações.
- **Pattern** / **Regular expression**: string usada para comparação em um critério.

Relaciona-se ao [[Motor de Regras de Negócio (capacidade)]] e à [[Execução de uma regra (criteria → action)]]. Termos do [[Glossário oficial (doc)]].
