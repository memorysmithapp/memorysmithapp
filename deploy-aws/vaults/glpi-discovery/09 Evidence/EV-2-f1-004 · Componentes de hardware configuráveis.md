> [!quote] modules/configuration/components.rst — "Components"
> "The hardware components that can be added to computers are configurable. A hardware component is defined by a type, a name, a manufacturer, a comment, and several fields specific to the type of component."
> - Ex.: para uma placa-mãe pode-se informar o chipset; para um Processor há campos próprios (aba **Main**).
> - É possível preencher outros tipos dentro do tipo *Other Components*, mas **não** é possível adicionar tipos além dos listados.
> - Ao selecionar um tipo (*Motherboard*, *Processor*...), redireciona à lista de componentes já criados.
> - Aba **Items**: visualiza os computadores ligados ao componente. As características de um componente só podem ser modificadas **para o item vinculado** (via *Elements* > Update), abrindo abas: Element-Component link, Management, Documents, Locks, Historical, Contracts, All.
> - Aba **Projects**: ver/associar projetos existentes ao componente (não cria novos). Também há abas Documents, Historical e All.
