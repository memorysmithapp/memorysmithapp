# EV-2-g3-021 · Aba Projetos (vincular projeto a um objeto)

> [!quote] source/tabs/projects.rst — "Projects"
> "This tab allows to attach a project to the change and displays already attached projects."
> A tabela-resumo traz por projeto: status, datas de abertura/fechamento, prioridade e supervisores.
> **Link a project**: selecionar na lista suspensa e **Add**. "You can not add a new project by this step" — para criar novo, ir a **Tools > Projects**.
> **Unlink a project**: em **Tools > Projects > (projeto)**, aba Item, selecionar o item, **Actions**, **Delete permanently the relation with selected elements**, **Post**.
