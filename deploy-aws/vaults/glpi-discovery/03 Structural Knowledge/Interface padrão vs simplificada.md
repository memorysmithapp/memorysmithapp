# Interface padrão vs simplificada

O GLPI oferece duas interfaces de usuário, conforme o glossário oficial:

- **Interface padrão** (*Standard interface*): dá acesso a todas as funcionalidades.
- **Interface simplificada** (*Simplified interface*): dá acesso a um conjunto reduzido de funcionalidades, voltada a usuários finais (end users).

A interface disponível a cada usuário depende do seu [[Perfis e Direitos (RBAC)|perfil]]. Conteúdos como artigos da base de conhecimento podem ser expostos como [[Glossário oficial (doc)|FAQ]] para usuários que só têm acesso à interface simplificada.

Termos do [[Glossário oficial (doc)]]: *Standard interface*, *Simplified interface*.
