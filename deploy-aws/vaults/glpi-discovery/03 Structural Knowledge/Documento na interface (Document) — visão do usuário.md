# Documento na interface (Document) — visão do usuário

Objeto do módulo Management que armazena um arquivo digital ou web link, descrito por **name**, **comment** e um **heading** (cabeçalho hierárquico). Ver [[Campos do formulário de Documento]].

O arquivo pode vir de disco local, de um web link externo ou de um arquivo pré-transferido por FTP (`/files/_uploads/`), com MIME type opcional. Ver [[Adicionar um documento e anexar arquivo (procedimento)]].

Abas:
- **Associated Items** — todos os itens ligados ao documento (ver [[Itens vinculáveis a um documento]]);
- **Documents** — outros documentos anexados a este documento;
- Notes, Historical, All.
