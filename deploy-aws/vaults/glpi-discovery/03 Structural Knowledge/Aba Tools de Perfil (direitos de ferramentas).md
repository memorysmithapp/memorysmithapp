# Aba Tools de Perfil (direitos de ferramentas)

Aba do perfil que gere permissões sobre **notas, feeds RSS, bookmarks públicos, relatórios, reservas, base de conhecimento e projetos/tarefas** (além das 7 [[Permissões padrão de objetos|permissões padrão]], não relistadas).

## Interface simplificada
- **Read the FAQ** — ver os artigos da base publicados na FAQ.
- **Make a Reservation** — reservar um ativo.

## Interface padrão
- **Knowledge Base**: *Knowledge Base Administration* (administra o acesso à base); *Publish in the FAQ* (adiciona/remove artigo da FAQ).
- **Projects**: *See (Actor)* (projetos que criei ou dos quais sou supervisor/membro do grupo supervisor); *See All* (todos os projetos da entidade).
- **Tasks** (de projeto): *See (Actor)* (tarefas que criei); *Update (Actor)* (tarefas que criei ou das quais sou membro da equipe).
