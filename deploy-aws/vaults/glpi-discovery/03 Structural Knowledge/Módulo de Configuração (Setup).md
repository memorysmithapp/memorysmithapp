O **Módulo de Configuração** (menu **Setup** na interface padrão) reúne todas as opções de configuração administrativa do GLPI. É o ponto de entrada para ajustar o comportamento global do produto.

## Submenus / páginas
- **Configuração geral** (Setup > General) → [[Configuração Geral do GLPI (Setup - General)]]
- **Notificações** e **Receivers** (coletores)
- **Ações automáticas** → ver código [[Ações Automáticas (CronTask)]]
- **Autenticação** → ver código [[Autenticação (Auth)]]
- **Plugins** → ver código [[Sistema de Plugins (Hooks)]], [[Plugins e Marketplace]]
- **Critérios de unicidade** → [[Unicidade de Campos (fields unicity)]]
- **Links externos** → [[Links Externos (external links)]]
- **Dropdowns** (listas suspensas) → ver [[Dropdown (lista suspensa customizável)]]
- **Componentes** → [[Componentes de Hardware Configuráveis]]
- **Definições de ativos** → ver código [[Ativos Customizáveis (AssetDefinition)]]
- **Níveis de serviço** → ver código [[SLM, SLA e OLA]]

> [!note]
> A visibilidade e edição desses itens dependem dos direitos do perfil do usuário — ver [[Perfis e Direitos (RBAC)]].
