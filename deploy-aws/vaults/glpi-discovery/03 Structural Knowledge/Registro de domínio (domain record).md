# Registro de domínio (domain record)

Um **Domain record** armazena os tipos de registro encontrados numa **zona DNS** ou arquivo de configuração DNS: TXT, A, PTR, SDA, CNAME, entre outros. Deve obrigatoriamente estar **associado a um objeto [[Domínio (Internet domain)|Domain]]**.

> [!note] Tipos customizáveis
> Os tipos de registro **não se limitam** aos padrão e podem ser customizados via gestão de listas suspensas ([[Dropdown (lista suspensa customizável)]]).

Campos: Name, Record type, Technician in charge, Group in charge, Creation date, TTL, Data — ver [[Campos de um Registro de domínio]]. A criação segue o [[Criação de um registro de domínio (fluxo)]].
