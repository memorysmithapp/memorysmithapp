# Campos da aba Portas de rede

Aba **Network Ports** — gerencia as portas de rede associadas ao equipamento (comum a todos os tipos de hardware e ao ativo não gerenciado). Campos visíveis:

Name · Port number · MTU · Speed · Internal status · Last change · Number of I/O bytes · Number of I/O errors · Duplex · VLAN · Connected to · Connection · Deleted.
