# Campos de um Registro de domínio

Campos preenchidos ao criar um [[Registro de domínio (domain record)]]:

| Campo | Semântica |
|-------|-----------|
| **Name** | Nome do registro. |
| **Record type** | Tipo do registro DNS (TXT, A, PTR, SDA, CNAME…); customizável via dropdown. |
| **Technician in charge** | Técnico responsável. |
| **Group in charge** | Grupo responsável. |
| **Creation date** | Data de criação. |
| **TTL** | Time to live do registro. |
| **Data** | Conteúdo/valor do registro. |

O registro deve estar associado a um [[Domínio (Internet domain)|Domain]]. Fluxo em [[Criação de um registro de domínio (fluxo)]].
